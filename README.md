# 儿童天赋测评 H5

纯 HTML/CSS/JavaScript 单文件移动端应用。直接双击 `index.html` 即可运行，无需服务端与第三方依赖。

## 功能

- 快速版：16 题、八大智能简明报告
- 精准版：50 题，包含16道天赋观察、24道RIASEC职业兴趣、6道行为风格和4道情境取舍
- 18类职业族、108个唯一代表职业及相关专业方向；结果优先展示最相关的5类、每类6个职业
- 快速版升级精准版时自动带入已答 16 题，再补做34题
- `localStorage` 自动保存资料与作答进度
- 320–480px 手机宽度适配
- 关于页、重新测评、截图保存提示

## 匹配模型

职业排序综合职业兴趣40%、观察能力25%、天赋表现20%、行为风格15%，并对关键维度明显不足的方向轻度扣分。五级答案统一转换为0-100标准化指数；该指数用于当前报告内排序，不表示未来从事某职业的概率。结果页显示作答完整度、答案区分度和复核提示。

职业兴趣结构参考 O*NET 30.3 Career Interest Types 与移动端 Mini-IP 的精简思路，题目按儿童日常情境改写；职业和专业采用“职业族 → 代表职业 → 相关专业方向”的分层展示。产品仍属于家庭成长观察工具，不是标准化心理测验或升学录取建议。

## 本地预览

```powershell
Start-Process .\index.html
```

也可以在目录运行静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。
