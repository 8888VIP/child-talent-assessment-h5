# 儿童天赋测评 H5

纯 HTML/CSS/JavaScript 单文件移动端应用。直接双击 `index.html` 即可运行，无需服务端与第三方依赖。

## 功能

- 快速版：16 题、八大智能简明报告
- 精准版：96 题，覆盖八大智能、RIASEC职业兴趣、六类核心能力、六类行为风格、性格偏好与情境取舍
- 18类职业族、72个代表职业和对应本科专业路径
- 快速版升级精准版时自动带入已答 16 题，再补做80题
- `localStorage` 自动保存资料与作答进度
- 320–480px 手机宽度适配
- 关于页、重新测评、截图保存提示

## 匹配模型

职业排序综合职业兴趣30%、核心能力25%、行为风格20%、天赋观察15%、性格偏好10%，并对关键维度明显不匹配的方向扣分。结果页同时显示作答可信度；当多个方向接近时会提示并行探索，而不是强行给出唯一专业。

题目与职业结构参考 O*NET 30.3 的 Career Interest Types、Work Styles、Abilities/Content Model；专业名称按教育部《普通高等学校本科专业目录（2026年）》校准。产品仍属于家庭成长观察工具，不是标准化心理测验或升学录取建议。

## 本地预览

```powershell
Start-Process .\index.html
```

也可以在目录运行静态服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。
